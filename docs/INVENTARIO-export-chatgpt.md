# Inventário do site Casa Rosa

**Tipo:** site estático puro. O HTML, o CSS e o JavaScript estão em `index.html`; imagens, ícones e fontes ficam em `assets/`.

**Build:** não precisa de build; não há framework, dependências ou `package.json`. Para testar localmente, execute `python3 -m http.server 8000` na pasta raiz e abra `http://localhost:8000`.

**Hospedagem:** envie o conteúdo desta pasta para a raiz do seu serviço de hospedagem. Os assets e fontes usados pelo site têm caminhos relativos. Os links de WhatsApp e do mapa continuam apontando para seus serviços externos.
